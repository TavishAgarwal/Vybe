# Changelog

All notable changes to Vybe are documented in this file.
Format: [Semantic Versioning](https://semver.org)

## [1.0.0] — 2025-05-09

### Added
- Weekly themed challenge feed with full-screen vertical video
- In-app camera recording (max 60 seconds) with AR filters
- Royalty-free music library for entry backing tracks
- 5-layer AI + human moderation pipeline
- Real-time leaderboard with 30-second update interval
- Cinematic Sunday winner reveal screen with confetti
- Creator profiles with Vybe Score and badge system
- Vybe Coins economy (earn by participating)
- Positivity-first comment system with real-time filtering
- Supabase Realtime vote count updates
- Firebase Cloud Messaging push notifications
- Challenge archive (all past winners and challenges)
- Moderation status screen for creators
- Strike system with appeal process
- Deep link support for notifications
