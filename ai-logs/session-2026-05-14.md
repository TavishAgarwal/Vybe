## Problems Identified & Resolved

### 1. Video Playback — Black Screen
**Root Cause:** The original `expo-av` / `expo-video` implementation attempted to mount
multiple native video players simultaneously, crashing in Expo Go due to the New
Architecture (NitroModules) requirement.

**Fix:** Adopted a **single-instance player architecture** (`ActiveVideo` component).
Only the currently visible FlatList cell mounts an `<VideoView>` — all other cells
display a static `<Image>` thumbnail. This eliminated memory pressure and native crashes.

### 2. Gray Screen / Dark Bottom Half
**Root Cause:** The FlatList cell height did not account for the bottom tab bar, causing
the last ~60px of each cell to render as empty black space below the content.

**Fix:** Used `useBottomTabBarHeight()` to calculate the correct item height:
`ITEM_H = screenHeight - tabBarHeight`. Applied `snapToInterval` matching the same value
to ensure pixel-perfect paging.

### 3. Caption / Thumbnail Mismatch
**Root Cause:** Separate arrays for images (`THUMBNAILS[]`) and captions (`CAPTIONS[]`)
of different lengths caused index misalignment — caption at index N did not correspond
to the image at index N.

**Fix:** Merged into a single `FEED[]` array of `{ img, cap }` pairs. Each entry now
carries its own coherent image ID and caption string, eliminating any index drift.

### 4. Video URLs Not Loading
**Root Cause:** Pexels video URLs require authentication headers and are often
rate-limited or geo-restricted, causing silent playback failures.

**Fix:** Switched to Google's public sample video CDN
(`storage.googleapis.com/gtv-videos-bucket/sample/...`) which requires no auth and
is globally accessible.

## Architecture Decisions

### Home Feed — Single-Player Pattern
```
FlatList
  ├── Cell 0: <Image thumbnail />  (inactive)
  ├── Cell 1: <Image thumbnail /> + <ActiveVideo uri={...} />  (active)
  └── Cell 2: <Image thumbnail />  (inactive)
```
- Only **one** `useVideoPlayer` hook is mounted at any time
- `onViewableItemsChanged` triggers active index changes
- Player auto-plays with `loop = true`
- `React.memo` on all cell components to prevent unnecessary re-renders

### Data Model
- 35 unique users with distinct avatars, handles, and scores
- 35 paired `{image, caption}` entries from Pexels (static thumbnails)
- 8 Google sample videos cycled across entries
- Demo data falls back when Supabase DB returns empty
